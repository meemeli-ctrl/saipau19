# Ohjeet Claude Codelle tässä projektissa

Lue ja noudata **[AGENTS.md](AGENTS.md)** (repon juuressa) ennen mitään
git-toimintoa (`add`/`commit`/`push`/`merge`) tai `firebase deploy` -komentoa.
Sama tiedosto koskee myös muita tässä työtilassa käytössä olevia
AI-avustimia (Antigravity, GitHub Copilot) – älä oleta että olet ainoa joka
muokkaa tätä repoa.

Lyhyesti: muokkaa paikallisesti vapaasti, mutta committaa/pushaa GitHubiin ja
julkaise Firebaseen **vain kun käyttäjä pyytää sitä juuri sillä hetkellä**,
kumpikin erillisenä, nimenomaisena pyyntönä.
